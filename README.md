# Sprout Mobile 🌱

**Plan less. Start sooner. Finish something.**

Sprout is a local-first Pomodoro and AI planning app that helps you decide what to do next, focus on it, and move forward when you get stuck.

## Product principles

- **Local-first:** planning, focus sessions, and history work offline.
- **AI is optional:** core productivity never depends on an LLM.
- **AI proposes, you confirm:** suggestions never silently change user data.
- **Bring your own model:** Sprout is designed for user-supplied API keys and provider-neutral AI adapters.
- **One closed loop:** Capture → Plan → Focus → Outcome → Adapt.
- **Privacy by design:** task content is never analytics data.

## v1

Android first, built with React Native + Expo + TypeScript. The v1 finish line is a production Google Play release with planning, Pomodoro focus sessions, outcome tracking, and three focused AI capabilities:

1. Break a task down.
2. Suggest a measurable session goal.
3. Suggest one concrete next step when blocked.
