# Product

> Plan less. Start sooner. Finish something.

Sprout helps a user decide what to do next, focus on it, and move forward when stuck.

## v1 loop

Capture → Plan → Focus → Outcome → Adapt.

## v1 AI

- Break a vague task into 3–6 suggested steps.
- Suggest a measurable focus-session goal.
- When blocked, suggest one concrete next action.

AI proposes. The user confirms. No AI response silently mutates user data.

## Finish line

v1 is done only when the Android app is production-published on Google Play and the portfolio links to the live listing.
