# Security and privacy

- Core features work without an account or network connection.
- LLM/API keys are BYOK-first and stored only in secure device storage.
- Secrets never live in source control, SQLite, logs, crash reports, or analytics.
- AI receives only context needed for the explicit request.
- Task text and notes are private content, not telemetry.
- AI is opt-in and all proposed writes require user confirmation.
